## Contributing

All hub members with code responsibilities work out of this repository.

1. Clone the repo and create a branch off `main` for your work.

   ```bash
   git checkout -b <workstream>/<short-description>
   ```

2. Keep commits small and descriptive.
3. Open a pull request into `main` and request review from another hub member.
4. Do not push directly to `main`.

Branch naming: `web/`, `chatbot/`, `brand/`, `docs/` prefixes matching the workstream.
